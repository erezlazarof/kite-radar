# רדאר קייט

תחזית רוח לספוטי הקייטסרפינג בישראל, עם פסק דין "ללכת לים?" לכל חוף.
עברית, RTL, מותאם לנייד. חינמי, בלי מסד נתונים ובלי build step.

## הרצה מקומית

```
dev.bat
```

מעלה את האתר על <http://127.0.0.1:3300>. פתיחת `public/index.html` מהדיסק **לא תעבוד** — ES modules חסומים על `file://`.

## בדיקות

```
npm test
```

34+ בדיקות. כל אחת מהן היא **כלל בטיחות**, לא בדיקת רגרסיה — אם אחת נופלת, האפליקציה עלולה לשלוח מישהו לים בתנאים שגויים. להריץ לפני כל push.

## מבנה

| נתיב | מה |
|---|---|
| `public/data/spots.json` | **הרג'יסטר.** גיט הוא מסד הנתונים. כל חריג פר-ספוט הוא נתון כאן, לא ענף בקוד |
| `public/js/verdict/` | **מנוע פסק הדין. טהור** — בלי DOM, בלי fetch, בלי `Date.now()`. רץ גם בדפדפן וגם ב-Worker של ההתראות |
| `public/js/sources/` | משיכת נתונים. Open-Meteo נקרא **ישירות מהדפדפן**, במכוון |
| `public/js/ui/` | רינדור |
| `functions/api/obs.js` | Pages Function — proxy למקורות המדידה החיה (שלב 4) |
| `worker/` | Worker נפרד להתראות טלגרם. **המקום היחיד שמחזיק סוד** (שלב 7) |

## כללי בטיחות מקודדים

אלה לא העדפות עיצוב. הם קבועים במנוע ומכוסים בבדיקות:

1. **אין מסלול קוד מנתון ישן או חסר אל ירוק.**
2. **אפור (`unknown`) אינו אדום.** "לא יודעים" ≠ "יודעים שרע".
3. **`blocked` (אסור / מחוץ לעונה) אינו אדום.** אסור ≠ מסוכן. ערבוב השניים מלמד משתמשים להתעלם מאדום.
4. **רוח מהחוף החוצה היא אדום ואי אפשר לעקוף אותה בניקוד.** החריג היחיד הוא `direction_overrides` — נתון ברג'יסטר, לא ענף בקוד. שם חי חוף אילת הצפוני, שבו הצפונית התרמית היא offshore *וזו צורת הגלישה הרגילה*.
5. **מהירות היא שער, לא רק רכיב.** כיוון מושלם לא הופך 10 קשר לרכיבים.
6. **דגלי סכנה מוצגים תמיד**, גם כשהמספר טוב.
7. **null לעולם לא ממולא באפס.** אין נתוני גלים לאילת ולכנרת — וזה נאמר, לא מומצא.

## למה אין build step

הנתונים זעירים (72 נקודות × ≤4 סדרות), והגרף הנדרש הוא מטאוגרם רוח ולא גרף גנרי — רקעי רצועות קשרים, מעטפת משבים, חצי כיוון. SVG בעבודת יד הוא פחות קוד מלהגדיר ספרייה לצורה הזו.

## פריסה

`git push` → Cloudflare Pages בונה ומעלה תוך ~30 שניות. אין פקודת פריסה ידנית לאתר.
ה-Worker של ההתראות נפרס בנפרד וידנית, כי הוא מחזיק את הסוד.
